# What this folder holds

In the mini registry, this folder holds:

- one folder per working round, with its evidence: commands, their output, passages quoted, at `_working/<round>/_evidence/`; each gets a folder of its own, named in place of the words in angle brackets. Why here: a review re-establishes a figure from the evidence, so the evidence sits beside the work it proves.

This folder was made at the inception of the project, on the owner's ruling of the map. The project's constants, `CONSTANTS.md`, record where each of these lives. A place changes only by a ruling, and files are never moved to follow it.
